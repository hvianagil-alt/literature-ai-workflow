# Sample papers (optional)

This folder is where you'd put a PDF you deliberately want tracked in git (see Option C in [`papers/README.md`](../README.md)).

No sample PDF ships in this repo by default — real papers carry copyright and redistribution restrictions, so we didn't want to guess wrong on your behalf. Instead, [`examples/`](../../examples/) contains fully worked *outputs* (a sample literature table, a sample journal article with results tables, and a sample lab report) built from clearly fictional placeholder papers, so you can see the destination of the workflow without needing a real PDF first.

If you want a real worked example here, a good choice is a paper you authored yourself, or an arXiv preprint (check its license) — drop it in this folder and it will be tracked by git.
