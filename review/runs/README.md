# Review runs

Each real review (especially one that starts from a database export) gets a folder here:

`review/runs/<run-id>/`

That folder is the methods trail: identification set, fetch log, PRISMA counts, phase/token estimates, `synthesis-rationale.md`, optional `gap-retrieval/` (extra OA searches), and a copy of the article. Per-paper working notes still go to `review/notes/` as well. Do not write `article.md` until the rationale file exists **and** extra retrieval for interpretation gaps has been attempted or logged as not possible. Token estimates stay in `usage-log.md`.

See `.cursor/skills/prisma-logging/SKILL.md`.
