# Review runs

Each real review (especially one that starts from a database export) gets a folder here:

`review/runs/<run-id>/`

That folder is the methods trail: identification set, fetch log, PRISMA counts, phase/token estimates, and a copy of the article. Per-paper working notes still go to `review/notes/` as well.

See `.cursor/skills/prisma-logging/SKILL.md`.
