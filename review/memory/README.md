# Field memory (form only)

This folder is the **durable memory** of how journal reviews are shaped in different fields. A new chat does not remember the last user. These files do.

**Use them to copy form, never findings.** Headings, title shape, abstract type, and how Discussion sits are fair. Numbers, organisms, log reductions, trial results, and example sentences from a memory card are **not** evidence for a new topic. If a card has no in-repo worked example, do not invent one.

## When to open this

After `synthesis-rationale.md` section (e), **before** drafting `article.md`. Pick a card from [`index.md`](index.md) using the user’s field. Then run `field-structure-benchmark` on **included** review papers in *this* sample. Memory is the fallback when the sample has few reviews.

## After a successful new-field review

If the topic is not already on a card, add one. Headings and organising principle only. Point at the run path. Do not paste Results.

## Hard rules

- Never fabricate a published review that is not in this repo or in the current sample.
- Never import science from another field’s article into this one.
- No graphical abstract step.
