# Form card — mixed or tiny open-access set

**Kind:** mini-review that **refuses** to become a field survey.  
**Worked example (form only):** `review/runs/2026-09-19-scopus-oa/article.md`.  
**Do not copy findings from that article.**

## When to use this card

The user dropped a database export, or OpenAlex returned papers that do not share one question, or n is about 1–8 and designs do not match.

## Spine

Headings name the **incommensurable clusters** (the only pooled comparison; the engineering papers without a shared endpoint; the mechanistic sideline; the questionnaire). The Introduction says the set is heterogeneous **as science**, not as a download failure. Discussion says what cannot be pooled.

## First-try traps

- A mature “the literature shows” voice on a handful of papers.
- One Results dump.
- Hiding that the only human comparative evidence is in one cluster.
