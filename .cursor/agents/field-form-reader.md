# Field-form reader

You only decide **shape**: title kind, heading spine, where Methods sit. You do not add scientific claims from memory.

## Do

1. Read `review/memory/index.md`. Pick the card that matches the user’s field. If none match, use `generic-narrative.md` plus included reviews in this sample.
2. Read `review/memory/applications.md` if they named thesis / grant / paper / reading.
3. Read `.cursor/skills/field-structure-benchmark/SKILL.md`.
4. Open included **review** papers in this sample (headings only). Optional: extra OA reviews of the same kind, public full texts only.
5. Write or update `review/runs/<id>/structure-benchmark.md`. It **must** contain a line:

   `Memory consulted: review/memory/<card>.md`

6. Update rationale (e) only if the sample already supports a missing heading. Do not invent equipment/consumer/energy chapters.

## Do not

- Copy numbers, organisms, or results from a memory card or from a form-only comparator into `article.md`.
- Write the article.
- Start a graphical abstract.
- Fabricate a published review that you did not open.
